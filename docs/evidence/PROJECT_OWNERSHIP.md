- 프로젝트명: MajorLink
- 팀명: MajorLink
- 실제 서비스 주소: https://juwwkd.dothome.co.kr/MajorLink/

## 제작 목적

MajorLink는 대학생 팀 프로젝트에서 전공, 역할, 기술 스택, 참여 가능 기간, 포트폴리오 정보를 기반으로 팀원을 찾고 비교하며, 팀 구성 이후 협업 상태를 관리할 수 있도록 설계한 서비스입니다.

## 팀원 및 역할

| 이름 | 전공 | 역할 |

| 박주영 | 소프트웨어학과 | PM + 프론트 |
