# MajorLink Google Forms 사용자 조사 요약

## 목적

MajorLink 서비스 기획의 근거를 남기기 위해 Google Forms 조사 결과 캡처를 보관합니다.

조사 목적은 대학생 팀 프로젝트에서 팀원 모집, 역할 분담, 전공 간 협업, 포트폴리오 정리 과정의 불편함과 MajorLink와 같은 서비스 사용 의향을 확인하는 것입니다.

| 원본 응답 공개 여부 | 원본 응답 파일은 공개하지 않고, 비식별 결과 캡처만 보관 |

## 핵심 요약

- 응답자는 1학년부터 졸업 예정/졸업생까지 분포되어 있습니다.
- 컴퓨터공학/소프트웨어/IT 계열 응답자가 가장 많고, 인문/사회/교육, 디자인/예술, 경영/경제/창업 등 다양한 전공 계열이 포함되어 있습니다.
- 공모전, 졸업작품, 캡스톤디자인, 사이드프로젝트 참여 경험은 `있다` 40.4%, `없다` 38.5%, `계획이 있다` 21.2%로 나타났습니다.
- 프로젝트 팀원을 구하는 과정에서 `어려운 편이었다` 응답이 가장 크게 나타났고, 실력/경험 확인, 역할 분담, 참여 가능 기간 확인, 경험 부족 등이 주요 어려움으로 확인되었습니다.
- 팀원 모집 경로는 `같은 학과 친구`가 가장 높았고, 동아리/학회, 교수님 또는 지인 추천, 구해본 적 없음이 뒤를 이었습니다.
- 다른 전공 학생과 협업하는 프로젝트에 참여할 의향은 긍정 응답이 높게 나타났습니다.
- MajorLink와 같은 서비스 사용 의향은 `사용할 것 같다` 48.1%, `꼭 사용해보고 싶다` 19.2%, `보통이다` 28.8%로 나타났습니다.
- 필요 기능으로는 전공/역할 기반 학생 프로필, 팀원 간 댓글/소통, 팀원 후기/평가, 프로젝트 모집 등록, 공모전/대외활동 정보 연동 등이 높게 나타났습니다.
- 자유응답에서는 공모전 자동 매칭, 같은 스킬 기반 매칭, 접근성 높은 UX, 포트폴리오 비교, 취업 연계, 학교/지역 기반 운영, 평가 공유 기능 등이 제안되었습니다.
- 프리미엄 기능은 무료 사용 의향이 가장 높고, 낮은 월 구독료 조건에서는 일부 지불 의향도 확인됩니다.

## 기획 반영 포인트

| 조사 결과 | MajorLink 반영 방향 |
|---|---|
| 팀원 실력/경험 확인이 어렵다 | 전공/역할 기반 학생 프로필, 포트폴리오 링크, 참여 이력 표시 |
| 팀 프로젝트 경험이 없어 시작이 어렵다 | 프로젝트 모집 등록, 역할 템플릿, 초보자도 이해하기 쉬운 지원 흐름 |
| 같은 학과 친구 중심으로 팀을 구한다 | 전공 간 협업을 확장할 수 있는 매칭/탐색 화면 |
| 다른 전공 협업 의향이 있다 | 디자인, 기획, 프론트, 백엔드 등 역할 기반 매칭 |
| 댓글/소통, 후기/평가 기능 수요가 있다 | 팀원 간 커뮤니케이션, 후기/평가, 진행 관리 보드 |
| 포트폴리오 정리에 어려움이 있다 | 프로젝트 완료 후 포트폴리오 자동 정리/PDF 저장 방향 |
