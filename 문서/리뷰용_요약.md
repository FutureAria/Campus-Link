# Campus Link 리뷰용 요약

## 한 줄 소개

Campus Link는 대학생 팀 프로젝트에서 전공, 역할, 기술 스택을 기준으로 팀원을 찾고 협업을 관리하는 전공 기반 팀빌딩 서비스입니다.

## 서비스 주소

- 실제 서비스: https://juwwkd.dothome.co.kr/Campus-Link/
- GitHub 저장소: https://github.com/FutureAria/Campus-Link

## 문제 정의

대학생 팀 프로젝트에서는 팀원을 구할 때 전공, 역할, 기술 스택, 일정, 포트폴리오 정보를 한눈에 비교하기 어렵습니다.

그 결과 아래 문제가 생깁니다.

- 필요한 역할이 명확하지 않은 상태로 팀을 구성함
- 프론트엔드, 백엔드, 기획, 디자인 역할이 불균형하게 배정됨
- 지원자의 실제 역량과 프로젝트 요구사항을 비교하기 어려움
- 팀 구성 이후 협업 현황을 관리하기 어려움

## 해결 방향

Campus Link는 프로젝트 리더가 필요한 역할을 등록하고, 지원자를 역할/전공/기술/일정/포트폴리오 기준으로 비교할 수 있는 흐름을 제안합니다.

팀 구성 이후에는 칸반 보드와 자료 관리 화면을 통해 협업 상태를 한눈에 볼 수 있도록 설계했습니다.

## 핵심 기능

- 프로젝트 등록
- 역할 기반 팀원 모집
- 지원자 적합도 비교
- 전공별 색상 구분
- 팀 구성 후 협업 보드
- 프로젝트 자료 관리
- 포트폴리오 산출물 관리

## 팀 구성

| 이름 | 전공 | 역할 |
|---|---|---|
| 박주영 | 소프트웨어학과 | PM + 프론트 |
| 김상윤 | 정보보안학과 | 프론트 |
| 우가은 | 경영학과 | 기획 |
| 오영은 | 시각디자인과 | 디자인 |
| 정진명 | 멀티미디어학과 | 백엔드 |
| 신정민 | 정보보호학과 | 백엔드 |

## 사용자 조사 근거

Google Forms 사전 조사에서 52개의 응답을 확보했습니다.

조사 결과는 팀원 모집의 어려움, 다른 전공 협업 의향, 서비스 사용 의향, 필요한 기능, 포트폴리오 정리 어려움 등을 확인하는 데 사용했습니다.

자세한 조사 요약과 캡처는 `문서/증빙자료/사용자조사_구글폼/구글폼_사용자조사_요약.md`에서 확인할 수 있습니다.

## 저작권 및 사용 제한

Campus Link 프로젝트 산출물은 Campus Link 팀의 공동 제작물입니다.

이 저장소는 제작 시점과 산출물 보관을 위한 공개 기록 용도로 사용하며, 무단 복제, 배포, 수정, 상업적 이용, 2차 저작물 제작을 허가하지 않습니다.
