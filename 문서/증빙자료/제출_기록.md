# Campus Link 제출 기록

## 현재 상태

현재 사용자 제공 정보 기준으로 Campus Link의 공모전/수업 제출 기록은 없습니다.

이 문서는 향후 제출 기록이 생겼을 때 누락 없이 기록하기 위한 양식입니다.

## 제출 기록 표

| 날짜 | 제출처 | 제출 유형 | 제출 자료 | 제출자 | 비고 |
|---|---|---|---|---|---|
| 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 | 현재 제출 기록 없음 |

## 기록할 항목

향후 공모전, 수업, 발표, 심사, 외부 제출이 생기면 아래 정보를 기록합니다.

- 제출일
- 제출처
- 담당 교수/기관/심사자
- 제출한 파일명
- 제출 방식
- 제출 URL
- 접수 번호
- 확인 메일 또는 접수 화면 캡처
- 제출 당시 GitHub 커밋 해시
- 제출 당시 서비스 URL

## 보관 권장 자료

- 제출 완료 화면 캡처
- 제출 확인 메일
- 제출 파일 원본
- 발표 당시 PDF
- 발표 당시 사이트 캡처
- GitHub 커밋 해시
- 팀원 회의 기록

## 주의

제출 기록은 저작권 및 제작 시점 증빙에 도움이 될 수 있지만, 법적 권리 확정을 자동으로 보장하지는 않습니다.
