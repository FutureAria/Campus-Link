## 프로젝트 설명

MajorLink는 대학생 팀 프로젝트에서 전공, 역할, 기술 스택, 참여 가능 기간, 포트폴리오 정보를 기반으로 팀원을 찾고 비교하며, 팀 구성 이후 협업 상태를 관리할 수 있도록 설계한 서비스입니다.

주요 화면은 다음 흐름을 보여줍니다.

- 프로젝트 등록 및 역할 정의
- 지원자 목록과 적합도 비교
- 전공/역할 기반 팀 구성
- 칸반 보드 기반 협업 관리
- 프로젝트 종료 후 산출물 관리

## PDF 재생성 기록

- 기존 PDF에서 GitHub 미리보기 시 한글이 깨져 보이는 문제가 확인되어, 업로드된 최종 발표자료 PPTX를 기준으로 PDF를 다시 생성했습니다.
- 재생성 방식: PPTX 슬라이드 이미지 27장을 추출한 뒤 PDF로 병합
- 확인 내용: 첫 페이지 렌더링에서 한글 표시 정상 확인

## 한계

GitHub 커밋 기록과 파일 해시는 제작 시점 및 파일 동일성에 대한 보조 증거로 활용할 수 있지만, 법적 권리를 자동으로 확정하지는 않습니다.

중요한 제출, 공모전, 사업화, 분쟁 대응이 필요한 경우에는 다음 자료를 함께 보관하는 것이 좋습니다.

- 원본 작업 파일
- 작업 과정 캡처
- 발표/제출 기록
- 팀원 간 회의 기록
- 공식 저작권 등록 또는 공증 자료
- 배포 URL과 업로드 이력
- 특허/BM/상표 검토 기록
- 원본증명 또는 공식 등록 신청 기록
