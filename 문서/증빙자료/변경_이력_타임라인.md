# Campus Link 증빙 변경 이력 타임라인

## 목적

이 문서는 Campus Link 저장소에 어떤 증빙 자료가 언제 추가되었는지 사람이 쉽게 확인할 수 있도록 정리한 보조 타임라인입니다.

GitHub 커밋 기록이 1차 기준이며, 이 문서는 커밋 내용을 사람이 읽기 쉽게 정리한 보조 문서입니다. 과거 시점 자료를 새로 추가하는 경우에도 실제 GitHub 추가 시각과 원본 파일의 생성/수정 시각을 구분해서 기록합니다.

## 기록 원칙

- GitHub 커밋 기록을 1차 기준으로 삼습니다.
- 과거 시점의 자료를 임의로 소급 작성하지 않습니다.
- 새 자료를 추가할 때는 GitHub 커밋 시간과 함께 기록합니다.
- 자료의 원본 파일명, 저장소 경로, 해시를 가능한 한 함께 남깁니다.
- 수정이 필요한 경우 기존 기록을 삭제하지 않고 새 항목으로 추가합니다.
- 이 문서는 법적 권리 확정이 아니라 제작 과정과 보관 이력을 정리하는 목적입니다.

## 이후 운영 방식

앞으로 증빙 자료를 추가할 때는 아래 순서로 처리합니다.

1. 원본 파일 또는 캡처 파일을 저장소의 적절한 위치에 추가합니다.
2. 파일명을 한국어로 이해 가능하게 정리합니다.
3. `문서/증빙자료/파일_해시.md`에 SHA-256 해시를 추가합니다.
4. 이 문서의 변경 이력 표에 날짜/시간, 커밋, 변경 내용, 주요 파일을 추가합니다.
5. `README.md` 또는 `문서/증빙자료/제작_증빙.md`에서 찾을 수 있게 연결합니다.
6. 커밋 메시지는 추가한 자료의 성격이 드러나도록 작성합니다.

## 한계

이 타임라인은 GitHub 커밋 기록을 사람이 보기 쉽게 정리한 보조 문서입니다. 법적 권리 확정이나 분쟁 대응을 완전히 보장하지는 않습니다. 중요한 외부 제출, 사업화, 출원, 등록, 분쟁 가능성이 있을 경우 공식 등록, 원본증명, 공증, 전문가 검토를 별도로 진행하는 것이 좋습니다.
