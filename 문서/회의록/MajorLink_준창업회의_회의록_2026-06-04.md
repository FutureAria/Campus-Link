## 논의 내용

### 프로젝트 이름 및 서비스 포지션

- 카카오톡 투표를 통해 프로젝트 이름 후보를 공유하고 팀 의견을 수집했습니다.
- 이름 후보는 Campus Link, TeamUp, Portfolio Lab 등이 논의되었습니다.
- 현재 저장소와 제출 문서의 프로젝트명은 `MajorLink`로 유지합니다.

### 수익모델 보완

- 프리미엄 모델과 사용량 기반 모델을 비교했습니다.
- 프리미엄 모델은 기본 기능 무료 제공 후 고급 기능을 유료화하는 방식으로 논의했습니다.
- 사용량 기반 모델은 쓴 만큼 결제하는 방식이지만, 초기 대학생 사용자 대상 서비스에서는 매출 예측이 어렵다는 점을 함께 검토했습니다.
- 공모전 문서에서는 과장된 매출 전망보다 학교/학과/동아리/창업지원단 대상 B2B 확장 가능성과 무료 MVP 검증 이후 유료 기능 전환 가능성을 중심으로 정리합니다.

### 선행연구 기반 점수 설계

- 지원자 비교 점수는 논문으로 검증 완료한 알고리즘이라고 표현하지 않습니다.
- 역할 매칭, 기술 스택, 참여 가능 기간, 관심 분야, 포트폴리오 항목은 팀 구성/동료평가/프로젝트 기반 학습 관련 선행연구를 참고해 설계한 초기 가중치로 설명합니다.
- 현재 단계는 정적 HTML 기반 MVP 프로토타입이며, 실제 사용자 데이터 기반 검증은 향후 과제로 둡니다.

### 전공/직무 전환 희망자 지원

- 기존 전공이나 경력만으로 지원자를 판단하지 않고, 희망 역할, 학습 중인 기술, 성장 가능성, 포트폴리오 목표를 함께 보여주는 방향을 논의했습니다.
- 직무 전환 희망자가 불이익을 당하지 않는다고 단정하기보다, 자신의 학습 과정과 성장 가능성을 구조적으로 보여줄 수 있게 한다고 표현합니다.

### 서비스 화면 보완 아이디어

- 전공/학과/적성 카테고리를 기반으로 프로젝트에 적합한 지원자를 보여주는 흐름을 검토했습니다.
- 친구 초대나 계정 연결 방식은 추후 실제 서비스 기획 단계에서 개인정보와 보안 범위를 검토한 뒤 결정하기로 했습니다.

## 결정 사항

- 공모전/공개 문서에서는 구현되지 않은 기능을 구현 완료처럼 표현하지 않습니다.
- 지원자 점수는 선행연구 참고 기반의 초기 설계안으로 표현합니다.
- 직무 전환 지원은 `성장 경로 기반 프로필` 또는 `직무 전환 친화형 팀빌딩` 방향으로 정리합니다.
- 회의 스크린샷은 공개 저장소 업로드 전 개인정보 노출 가능성이 있는 영역을 제거하거나 가린 공개용 사본으로 보관합니다.
