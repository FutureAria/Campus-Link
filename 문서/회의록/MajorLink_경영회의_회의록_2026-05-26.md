## 4. 안건별 회의 내용

### 4.1 서비스명 검토

#### 논의 내용

현재 서비스명인 `Major` 또는 `MajorLink`는 변경 가능성을 열어두기로 했습니다.

회의 중에는 이름이 특정 의미를 너무 강하게 연상하지 않는 것이 좋다는 의견이 있었습니다. 서비스가 팀원 모집뿐 아니라 포트폴리오, 협업, 학교/기관 플랜까지 확장될 수 있기 때문입니다.

#### 이름 검토 기준

- 특정 전공이나 기능에만 묶이지 않는 이름
- 팀빌딩, 프로젝트, 협업, 포트폴리오까지 확장 가능한 이름
- 발음과 기억이 쉬운 이름
- 검색 시 혼동이 적은 이름
- 기존 서비스명, 상표, 도메인과 충돌 가능성이 낮은 이름

#### 결정 상태

- 서비스명 변경 여부는 확정하지 않음
- 후보명을 추가로 모아 비교하기로 함

### 4.2 타겟 고객

#### 논의 내용

기존에는 대학생 프로젝트 팀장을 중심으로 보았지만, 회의에서는 학년과 상황을 더 세분화해야 한다는 의견이 나왔습니다.

특히 대학생 3~4학년과 대학원생은 실제 프로젝트, 캡스톤, 졸업작품, 취업 포트폴리오 수요가 크기 때문에 주 타겟 후보로 언급되었습니다. 고등학교 2~3학년은 입시나 자사고 포트폴리오 수요 관점에서 확장 가능성이 있는 타겟으로 논의되었습니다.

#### 타겟 후보

| 구분 | 타겟 후보 | 니즈 | 회의 판단 |
|---|---|---|---|
| 고등학생 2~3학년 | 입시, 자사고, 포트폴리오 준비 학생 | 활동 기록, 팀 프로젝트 경험, 결과물 정리 | 확장 가능성 검토 |
| 대학생 1~2학년 | 초기 대학 생활, 가벼운 팀 프로젝트 | 팀 프로젝트 탐색, 경험 축적 | 사용 빈도가 낮을 수 있음 |
| 대학생 3~4학년 | 캡스톤, 졸업작품, 공모전, 취업 포트폴리오 준비 학생 | 팀원 모집, 실력 확인, 포트폴리오 정리 | 주 타겟 후보 |
| 대학원생 | 연구/프로젝트 협업 참여자 | 역할 명확화, 협업 기록, 전문성 기반 팀 구성 | 주 타겟 후보 |
| 학교/학과/비교과 운영자 | 학생 프로젝트 운영 담당자 | 프로젝트 현황 관리, 팀 구성 지원 | B2B 후보 |

#### 회의 중 나온 방향

- 주 타겟은 대학생 3~4학년과 대학원생을 우선 고려
- 고등학생 2~3학년은 입시/포트폴리오 시장 확장 후보로 검토
- 학년별 카테고리 구분 필요

#### 추가로 결정해야 할 것

- 1차 타겟을 대학생 3~4학년으로 확정할지
- 고등학생 입시/포트폴리오 시장을 초기 범위에 포함할지
- 대학원생을 초기 타겟에 포함할지
- 학년별 카테고리를 MVP에 포함할지, 이후 기능으로 둘지

### 4.3 문제 정의와 서비스 목적

#### 논의 내용

MajorLink의 목적은 크게 두 가지로 정리되었습니다.

1. 팀원 모집
2. 포트폴리오 정리

단순히 팀원을 구하는 서비스에서 끝나는 것이 아니라, 프로젝트 경험을 개인 포트폴리오로 연결하는 흐름이 중요하다는 방향이 논의되었습니다.

#### 문제 정의 후보

| 문제 | 설명 | 우선순위 |
|---|---|---|
| 팀원 모집 어려움 | 프로젝트에 맞는 사람을 찾기 어려움 | 높음 |
| 전공/역할 연결 부족 | 개발, 디자인, 기획, 경영 등 다른 전공 간 연결이 어려움 | 높음 |
| 지원자 실력 확인 어려움 | 지원자의 경험, 기술, 책임감을 판단하기 어려움 | 높음 |
| 프로젝트 경험 정리 어려움 | 프로젝트가 끝난 뒤 포트폴리오로 정리하기 어려움 | 높음 |
| 외부 채널 분산 | 오픈채팅, 개인 연락처, 노션 등 여러 채널로 흩어짐 | 중간 |

#### 정리 문장

MajorLink는 전공과 역할이 다른 학생들이 프로젝트 팀원을 찾고, 지원자의 역량을 비교하며, 프로젝트 경험을 포트폴리오로 정리할 수 있도록 돕는 협업 플랫폼입니다.

### 4.4 경쟁 서비스와 차별화

#### 논의 내용

경쟁 서비스와 비교할 때 차별화 문장은 더 간결해야 하며, 발표자료에서는 긴 설명보다 인포그래픽이나 화면 중심으로 보여주는 것이 좋다는 의견이 있었습니다.

#### 경쟁 서비스 후보

- 에브리타임
- 캠퍼스픽
- 링커리어
- 카카오톡 오픈채팅
- 노션
- GitHub
- 포트폴리오 템플릿 서비스
- 팀 협업 도구

#### 차별화 방향

| 차별화 포인트 | 설명 |
|---|---|
| 웹 안에서 해결 | 오픈채팅, 개인 연락처, 외부 문서로 흩어지지 않고 웹 서비스 안에서 팀 구성과 협업을 관리 |
| 내부 커뮤니케이션 | 개인 번호를 바로 공유하지 않고 서비스 안에서 필요한 소통을 처리 |
| 지원자 비교 | 지원자의 전공, 역할, 기술, 포트폴리오를 한눈에 비교 |
| 상세 프로필 | 쇼핑몰 상세 페이지처럼 지원자의 정보를 구조적으로 보여줌 |
| 프로젝트 이후 정리 | 팀 구성 이후 결과물을 포트폴리오로 연결 |
| 협업 기능 연동 | 일정 수준 이상의 협업/관리 기능을 유료 기능으로 확장 가능 |

#### 차별화 문장 후보

MajorLink는 팀원 모집부터 지원자 비교, 내부 협업, 포트폴리오 정리까지 웹 안에서 연결하는 전공 기반 프로젝트 팀빌딩 플랫폼입니다.

#### 추가로 정리할 것

- 경쟁 서비스별 화면/기능 비교표
- 발표자료에 넣을 간결한 차별화 문장
- 인포그래픽으로 보여줄 핵심 기능 3~4개

### 4.5 수익화 방향

#### 논의 내용

처음부터 팀원 매칭 자체를 유료화하기보다는, 매칭은 무료로 제공하고 일정 수준 이상의 협업/관리 기능이나 광고 제거, 팀 단위 기능을 유료화하는 방향이 논의되었습니다.

#### 주요 의견

- 매칭 자체는 무료로 제공
- 팀장에게 개인 번호가 바로 공개되지 않도록 외부 이탈을 줄이는 구조 검토
- 서비스 내부에서 팀 구성과 협업을 이어가게 만드는 것이 중요
- 일정 수준 이상의 기능을 유료화
- 월 구독 가격은 1,990원 수준 검토
- Canva처럼 기본 무료 + 유료 기능 확장 구조 참고
- 광고 제거 기능을 월 구독에 포함하는 방안 검토
- 학교/비교과/창업지원단 대상 플랜 가능성 검토
- 창업 경진대회, 마케팅 프로젝트 등 퀄리티 높은 프로젝트와 연계 가능성 검토

#### 수익모델 후보

| 수익모델 | 대상 | 설명 | 상태 |
|---|---|---|---|
| 기본 매칭 무료 | 학생/팀장 | 프로젝트 등록, 지원, 기본 매칭은 무료 제공 | 방향성 합의 |
| 개인 월 구독 | 학생 | 광고 제거, 프로필 강화, 포트폴리오 기능 등 | 검토 |
| 팀 단위 결제 | 팀장/팀 | 일정 수준 이상의 협업 기능, 팀 관리 기능 유료화 | 검토 |
| 협업 기능 유료화 | 팀/기관 | 일정, 내부 소통, 지원자 관리, 프로젝트 진행 관리 | 검토 |
| 상세 프로필/포트폴리오 강화 | 개인 | 프로필을 한눈에 볼 수 있는 상세 페이지, 포트폴리오 정리 | 검토 |
| 학교/비교과 플랜 | 학교/학과/기관 | 비교과, 창업지원단, 캡스톤 관리용 플랜 | 장기 후보 |
| 광고 제거 | 개인/팀 | 구독 시 광고 제거 포함 | 검토 |

#### 가격 가정

| 상품 | 가격 가정 | 비고 |
|---|---:|---|
| 기본 매칭 | 무료 | 초기 유입용 |
| 개인 월 구독 | 월 1,990원 | 가정, 검증 필요 |
| 팀 단위 플랜 | 미정 | 협업 기능 범위에 따라 결정 |
| 학교/비교과 플랜 | 미정 | B2B 상담 필요 |

> 가격은 회의 중 나온 가정이며, 실제 가격 정책은 설문/인터뷰/시장 조사 후 수정해야 합니다.

#### 추가로 결정해야 할 것

- 개인 구독과 팀 단위 결제 중 어느 쪽을 우선할지
- 월 1,990원 가격이 적절한지
- 광고 제거가 실제 결제 이유가 될 수 있는지
- 협업 기능 중 어떤 기능을 유료로 둘지
- 학교/비교과 플랜을 발표자료에 장기 수익모델로 넣을지

### 4.6 MVP 범위

#### 논의 상태

MVP 범위는 회의 중 별도로 확정되지 않았습니다.

기존 자료와 회의 내용 기준으로는 아래 방향이 적절합니다.

#### MVP 포함 후보

| 구분 | 기능 | 이유 |
|---|---|---|
| 필수 | 프로젝트 등록 | 팀장이 팀원 모집을 시작하기 위한 기본 기능 |
| 필수 | 역할 등록 | 필요한 역할과 전공을 명확히 하기 위함 |
| 필수 | 지원자 프로필 | 지원자의 전공, 기술, 경험, 포트폴리오 확인 |
| 필수 | 지원자 비교 | MajorLink의 핵심 차별점 |
| 중요 | 포트폴리오 링크 | 지원자의 실력 확인 근거 |
| 중요 | 내부 소통/지원 관리 | 외부 오픈채팅 이탈을 줄이기 위한 기능 |

#### MVP 제외 후보

| 기능 | 이유 |
|---|---|
| 결제 기능 | 초기 MVP에서는 검증 후 도입 |
| 고급 칸반보드 | MVP 이후 확장 |
| 포트폴리오 PDF 자동 생성 | 수익화 후보로 이후 도입 |
| 학교 관리자 페이지 | B2B 확장 단계에서 도입 |
| 고급 광고 제거/구독 관리 | 수익모델 검증 후 도입 |

#### 추가로 결정해야 할 것

- 내부 채팅 또는 내부 문의 기능을 MVP에 포함할지
- 포트폴리오 상세 프로필을 MVP에 넣을지
- 결제 기능은 발표용 시나리오만 보여줄지, 실제 구현 범위에서 제외할지

### 4.7 검증 방법

#### 논의 상태

검증 방법은 회의 중 구체적으로 확정되지 않았습니다.

- 학생들이 월 1,990원 구독에 실제로 지불 의향이 있는가?
- 광고 제거가 결제 이유가 될 수 있는가?
- 팀 단위 결제가 개인 결제보다 현실적인가?
- 외부 오픈채팅 대신 서비스 내부에서 소통하는 구조를 선호하는가?
- 학교/비교과/창업지원단이 관리 도구로 사용할 가능성이 있는가?

## 5. 회의 결과 정리

### 5.1 현재 합의된 방향

- MajorLink는 팀원 모집과 포트폴리오 정리를 함께 다루는 프로젝트 팀빌딩 플랫폼으로 정리
- 초기 매칭은 무료로 제공하는 방향
- 서비스 내부에서 지원자 비교, 상세 프로필, 협업 흐름을 제공해 외부 채널 이탈을 줄이는 방향
- 수익화는 월 구독, 팀 단위 결제, 협업 기능 유료화, 학교/비교과 플랜을 함께 검토
- 가격은 월 1,990원 수준을 가정으로 두되, 실제 검증 필요

### 5.2 미정 / 추가 논의 필요

- 서비스명 변경 여부
- 1차 타겟을 대학생 3~4학년으로 확정할지, 고등학생/대학원생까지 포함할지
- MVP에 내부 채팅 또는 내부 소통 기능을 포함할지
- 결제 기능을 실제 MVP에 포함할지, 발표용 시나리오로만 둘지
- 포트폴리오 PDF 기능의 우선순위
- 학교/비교과 플랜을 어느 단계에서 추진할지
